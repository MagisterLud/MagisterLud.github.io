Computer Modern Unicode Serif, version 0.7.0

Four unmodified WOFF2 files from computer-modern 0.1.3:
https://www.npmjs.com/package/computer-modern/v/0.1.3
https://github.com/stevenpetryk/computer-modern

Original font project by Andrey V. Panov, based on Computer Modern:
https://cm-unicode.sourceforge.io/

Fonts are licensed under SIL Open Font License 1.1; see OFL.txt.
The copyright notice and license are included from the CMU webfont distribution:
https://github.com/bitmaks/cm-web-fonts/blob/master/font/Serif/OFL.txt

The CMU regular (internally weight 500) and italic faces are mapped to CSS
weight 400 for normal text, with the original bold faces mapped to 700.
The same Roman outlines are used, without modifying or subsetting the fonts.
